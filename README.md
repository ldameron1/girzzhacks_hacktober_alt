To transform the classic 1985 platformer paradigm into an intelligent, legally distinct, and competitive AI hackathon project, **5 fundamental rule alterations** have been implemented and documented:

| # | Alteration | Traditional Rule | GemmaKaizo Rule | Purpose |

## 🎮 What is GemmaKaizo?

**GemmaKaizo** is a retro 16-bit precision platformer inspired by Kaizo Mario and "rage games" (like *I Wanna Be The Guy*, *Syobon Action*, and *Celeste*), starring **Steamboat Willie** and managed by an adversarial AI Game Master.

Powered by **Gemma 4** (`gemma-4-26b-a4b-it`) via the Google Generative Language API, the AI audits granular behavioral telemetry after every run. It identifies player archetypes—such as *The Impatient Rusher*, *The Floaty Dreamer*, *The Paralyzed Hesitator*, or *The Greedy Coin Goblin*—and injects targeted Kaizo obstacles right where the player's comfort zones lie.

## ✨ Key Features

1. **Gemma 4 Kaizo Architect**:
   - Analyzes run telemetry and writes custom JSON patches to the level.
   - Deploys:
     - **Kaizo Blocks**: Invisible solid blocks that bonk the player mid-air into pits.
     - **Crumbling Floors**: Solid stone that collapses under sprinting momentum or hesitation.
     - **Ceiling Spikes**: Punishes excessive high-float jumps.
     - **Falling Spikes**: Triggers drop when player is near.
     - **Deceptive Bait Coins**: Lures greedy players into hazard arcs.
     - **Ambush Enemies**: Fast-moving patrol units.
2. **Steamboat Willie Protagonist**:
   - Procedural rubber-hose 1928 animation, pillbox captain hat, white button shorts, and idle steam whistle puff. 100% public domain.
3. **Streak-Based Game Over System**:
   - 5 consecutive deaths triggers the Gemma 4 Game Over screen.
4. **Autonomous Player Bot (OpenRouter / Gemma 4)**:
   - Built-in AI agent capable of playing the game autonomously.
   - Queries OpenRouter free decision models or Gemma 4 to formulate obstacle strategy plans.
   - 60 FPS reflex controller executes timed hops, wall kicks, and gap clears.
5. **Death Heatmap Overlay**:
   - Visual skull markers and radial glow displaying the exact death density across the stage.
6. **Speedrunner Ghost Path**:
   - Real-time parabolic physics raycaster showing the mathematical proof of clearance.
7. **Procedural 8-Bit Audio Synth**:
   - 100% Web Audio API procedural synthesis (jump, stomp, bonk, death jingle, victory fanfare, and dark Kaizo bassline BGM). Zero missing audio files!
8. **Robust Offline Simulation Mode**:
   - If offline or API rate limits occur, an internal heuristic engine takes over seamlessly so the game and presentations never stall.

## 🚀 Quickstart

### Prerequisites
- Node.js 18+ or Node.js 22+
- `GEMINI_API_KEY` or `GOOGLE_API_KEY` (configured locally in `~/.bashrc` or `.env`)
- (Optional) `OPENROUTER_API_KEY` for free player decision bot

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/ldameron1/girzzhacks_hacktober_alt.git
cd girzzhacks_hacktober_alt

# Install dependencies
npm install

# Start development server (serves frontend + backend on port 3000)
npm run dev
```

Open your browser to: **`http://localhost:3000`**
